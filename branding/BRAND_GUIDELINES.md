# BRAND_GUIDELINES.md — FABRI-CORE PRO

Guía de marca canónica. Fuente de verdad para la identidad visual de FABRI-CORE PRO.

## 1. Paleta oficial

| Nombre | Valor | Uso |
|--------|-------|-----|
| Negro principal | `#050505` | Fondo principal, superficies base |
| Negro mate | `#0B0B0B` | Fondo alternativo, tarjetas, paneles |
| Lima principal | `#C8FF00` | Acento funcional (estados activos, progreso, acciones principales) |
| Lima alternativo | `#B7FF32` | Hover de botones lima, variantes de acento |
| Blanco | `#FFFFFF` | Texto principal sobre fondos oscuros |

> El lima es color de acento funcional, **no** para rellenar toda la interfaz.

## 2. Tipografía

- Familia principal: **Inter**
- H1: 48px escritorio / 32px móvil
- H2: 32px escritorio / 24px móvil
- Texto normal: 16px
- Etiquetas: 12px, mayúsculas, letter-spacing moderado
- Botones: 14px, peso medio

## 3. Identidad gráfica

- Monograma F geométrico original (no deformar, no agregar gradientes ni sombras)
- Espacio de seguridad del logotipo: 12%
- Fondos sólidos como tratamiento predeterminado
- Retícula blueprint sutil (opcional, contexto técnico)
- Composiciones minimalistas, industriales, tecnológicas, de lujo
- Radios de botones: ~12px
- Transiciones de referencia: 150ms, curvas suaves
- Sombras discretas para superficies

## 4. Reglas de uso del logotipo

- No redibujar ni deformar el monograma F
- No alterar su geometría ni sus colores canónicos
- No agregar gradientes, efectos o sombras al logotipo sólido original
- Espacio de seguridad del 12% cuando corresponda

## 5. Aplicación por plataforma

### WEB
- Escritorio: navegación lateral, cabecera con contexto, gráficos amplios
- Móvil: responsive, no copiar layout de Android

### APP ANDROID
- Borde a borde, barras compactas, controles para el pulgar
- Jerarquía vertical, tarjetas compactas
- No comprimir web como APK
