Qué hace

Cinco módulos, ni uno de relleno.

La misma consola en las dos versiones. Todo lo que ves funciona: si un motor no está disponible, la interfaz lo dice en vez de simularlo.

Núcleo local

SQLite con las 13 tablas del contrato. En Android es la base del sistema; en la web es SQLite compilado a WASM, persistido en IndexedDB.

SQLite · FTS5

Chat con agente

Las preguntas van a una función Go en Vercel. Cada respuesta se guarda en tu base con su procedencia: el historial es tuyo.

/api/agent

Consola SQL

Consulta y modifica la base de verdad, con atajos para ver tablas, conteos y el estado de FTS5. Nada de un terminal de mentira.

SQL real

Memoria con procedencia

Cada hecho guarda de dónde vino y si está verificado. La búsqueda usa FTS5 cuando existe y cae a LIKE cuando no, avisándolo.

RAG honesto

Flujos en vivo

Un grafo que se mueve con eventos reales: cada escritura, consulta o llamada al agente deja su rastro. Sin animaciones decorativas.

eventos reales

FABRI-CORE para tu teléfono

  • Kotlin nativo, sin dependencias pesadas: APK de ~35 KB

Cómo funciona

Tres pasos y estás dentro.

Abre o instala

Entra a la app web o baja la APK. La primera vez se crea tu base local vacía, con las tablas listas.

Guarda y pregunta

Escribe hechos en Memoria y pregúntale al agente. Todo queda indexado y con su procedencia.

Consulta lo tuyo

Usa la consola SQL para ver, cruzar o exportar. Lo que hay es lo que ves: sin capas ocultas.

Malla en vivo

Cuatro capas, un solo estado.

El teléfono entra por la API, el cerebro decide, la nube pone la voz y esta web es la cara. Cada capa se consulta en vivo con tope de 5 s: si una está caída, se dice; nunca se muestra un «ok» inventado.
